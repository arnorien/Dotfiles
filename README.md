# Dotfiles
## vimrc
This configuration use vim-plug to manage plugins. Goyo is one of them : it's perfect for long distraction-free writing. In this file, Goyo is activate automatically when a markdown file is open.
## nvim
This configuration use LazyVim plugin manager. Mostly optimize for LaTex with the Blink plugin not distracting the text.
## hypr
This is my configuration of the Hyprland ecosystem :
- Hyprland
- Hypridle (to manage the suspend in case of inactivity)
- Hyprlock (simplest lock screen possible)
- Hyprpaper (to manage randomization of wallpapers -> in the dedicated directory)
